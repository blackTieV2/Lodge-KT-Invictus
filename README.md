# Lodge-KT-Invictus

A model-neutral repository for preserving operational memory, governance, and workflow continuity for a human-led Knight Templar preceptory knowledge system and companion web experience.

This repository is intentionally bootstrap-only at this stage. It is not an application deployment and it does not authorize implementation without stage review and human approval.

## Purpose

The project will support:
- persistent memory for an LLM orchestrator;
- operational documentation for Invictus Preceptory #724;
- a lightweight website/front-end for public or internal preceptory-facing information;
- a small database-backed backend for operational records and maintenance workflows;
- safe, governed, stage-based execution and evidence capture.
